# Acta de Criterios de Aceptación con Clientes

## Proyecto

Plataforma comunitaria pensada  para la preservación y transmisión de la lengua materna de Santa María Cuquila.

## Propósito del repositorio

Este repositorio contiene la documentación correspondiente a la validación de las historias de usuario y sus criterios de aceptación.

La revisión permite relacionar las necesidades de la comunidad con las funcionalidades propuestas para el proyecto.

## Documento principal

- [ACTA-CRITERIOS-ACEPTACION.md](ACTA-CRITERIOS-ACEPTACION.md)

El acta contiene:

- Datos generales.
- Problemática seleccionada.
- Validación de HU-01 a HU-06.
- Criterios de aceptación.
- Dictámenes individuales.
- Modificaciones y trazabilidad.
- Contexto de la comunidad.
- Consecuencias de las decisiones.
- Viabilidad.
- Alternativa propuesta.
- Conclusiones.
